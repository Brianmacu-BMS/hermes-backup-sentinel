# Changelog

## 0.1.0 — initial isolated candidate

- Offline audit of local date-named gzip-compressed tar backups.
- Explicit required-file and archived SQLite policies.
- Bounded worker execution with parent-owned private scratch cleanup.
- Native Hermes tool, slash command, and CLI registration through public context APIs.
- Approval-preserving terminal dispatch; operator-configured target roots and limits.
- Synthetic regression suites, reproducible demo, source-only deterministic packaging.

This is source/build scope, not a marketplace release or deployment receipt. Initial platform is Linux; native Hermes ZIP backups are not supported.
